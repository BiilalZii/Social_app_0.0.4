# تطبيق إدارة الخدمات الاجتماعية للموظفين (نسخة v4)

## المميزات

- **حسابان بنكيان منفصلان للميزانية**:
  1. حساب القروض — الأقساط المسددة تعود مباشرة إلى نفس الحساب (مبلغ متجدد)
  2. حساب المنح والنشاطات الأخرى — مصروف غير قابل للاسترجاع
- **إدارة النشاطات** (عيد المرأة، عيد العمال، خرجات سياحية...): إضافة/تعديل أنواع النشاطات
  وتحديد مستحقاتها المالية، وتسجيل استفادة كل موظف منها + شهادة استفادة قابلة للطباعة
- **إدارة أنواع المنح**: إضافة/تعديل/حذف كامل (بعد أن كان التعديل فقط متاحًا)
- **بحث شامل** في الموظفين والقروض والمنح والنشاطات
- **تقارير مفصلة قابلة للطباعة**:
  - تقرير ملخص شامل (يعرض الحسابين البنكيين منفصلين)
  - تقرير المنح (مع فلترة)
  - تقرير القروض (مع فلترة)
  - تقرير النشاطات (مع فلترة)
  - تقرير فردي لكل موظف (قروض + منح + نشاطات)
- إحصائيات ومجاميع في لوحة التحكم
- واجهة عربية محسّنة ومتجاوبة

## التشغيل المحلي

```bash
pip install -r requirements.txt
python app.py
```

## النشر على Render

- Build: `pip install -r requirements.txt`
- Start: `gunicorn app:app --bind 0.0.0.0:$PORT`

## ملاحظة عند الترقية من نسخة قديمة

إذا كانت قاعدة البيانات القديمة تحتوي على إعداد ميزانية واحد (`budget_total`)، سيتم عند
أول تشغيل نسخ قيمته تلقائيًا إلى ميزانيتي القروض والمنح/النشاطات كقيمة ابتدائية؛ يمكنك
تعديل كل واحدة بعدها من صفحة "الميزانية والحسابات".
